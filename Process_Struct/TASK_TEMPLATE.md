# Process_Struct 任务模板

复制到具体任务记录后填写，模板本身不启动计算。

- 目标：通用结构特征、畸变、容量与连通性中的哪项功能？
- 类型：工具包。
- 输入：pymatgen Structure、化学式或轨迹；填写绝对路径、格式、数据量及前置检查。
- 输出：结构特征、容量、畸变及轨迹转换结果；填写独立目标目录与已有文件处理规则。
- 入口：从 API.md 选择函数/类及确切签名。
- 环境：py1 或已确认的专用环境；记录关键依赖版本。
- 参数：逐项列出值、单位、默认值和材料适用条件。
- 随机性：如适用，记录种子、模型和采样配置。
- 副作用：记录会写哪些文件、是否启动模型/外部计算、是否需要 GPU。
- 重复运行：说明覆盖、追加、跳过或断点恢复策略。
- 验证：最小输入、预期输出、形状/单位/收敛检查；报告未验证项。
- 已知限制：包使用延迟导入；不同功能的可选依赖分开检查。位点容量为间距约束下的贪心可行估计，不保证最大装载数。

新功能优先采用 `run(input_path, output_dir=None, *, options...)` 或现有兼容接口，业务逻辑与 CLI 分开；不要为统一外观擅自改动现有参数名。
