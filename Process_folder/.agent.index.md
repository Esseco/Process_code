# Process_folder 索引

## 入口文件
| 优先级 | 文件 | 说明 |
|---|---|---|
| ★★★ | `Process_folder/__init__.py` | 包的统一入口，导出所有公共 API |

## 模块结构

```
Process_folder/
├── __init__.py          ← 包入口，导出 replace_hyphen 和 ensure_dir
├── Handle_Excel.py      ← CSV 数据清洗（连字符 → 下划线替换）
└── Handle_File.py       ← 文件系统操作（目录创建）
```

## 主要调用关系

```
用户代码
    │
    ├── from Process_folder import replace_hyphen
    │   └── Handle_Excel.replace_hyphen(df_f, exclude_cols)
    │       └── pandas.read_csv()          # 外部依赖
    │       └── pandas.DataFrame.astype()  # 列类型转换
    │       └── str.replace()              # 字符串替换
    │
    └── from Process_folder import ensure_dir
        └── Handle_File.ensure_dir(path: Path)
            └── pathlib.Path.mkdir()       # 创建目录（recursive）
```

## 依赖关系图

```
replace_hyphen (Handle_Excel)
  ├── 参数: df_f (str, CSV文件路径) , exclude_cols (list/str, 排除列)
  └── 返回: pd.DataFrame (清洗后的数据)

ensure_dir (Handle_File)
  ├── 参数: path (pathlib.Path, 目标目录路径)
  └── 返回: path (pathlib.Path, 同输入路径)
```

## 模块间依赖
- **Handle_Excel.py** ↔ **Handle_File.py**：无直接依赖
- **__init__.py** → Handle_Excel.py, Handle_File.py：导入并重新导出

## 外部依赖
- `pandas`：Handle_Excel.py 的 CSV 读取与数据操作
- `pathlib`：Handle_File.py 的路径操作（Python 标准库）
