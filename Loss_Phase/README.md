相稳定性相关训练数据与损失实验。

## 功能和使用条件

Train_auc.py 处理组成、能量、分组及 hull 数据；Loss_hull 提供自定义数据集和训练器；Loss_rank 目前没有功能源码，作为预留目录。需要匹配的 torch/CHGNet 环境。correct_energy 含特定 GGA+U 假设，异常时返回 0，可能掩盖数据错误；正式训练前单独核查修正逻辑、标签单位、分组与数据泄漏。

真实参数见 [API.md](API.md)，具体任务约定用 [TASK_TEMPLATE.md](TASK_TEMPLATE.md)。有 examples 时先填写其中顶部参数，每个功能独立运行。历史缺失依赖的入口不提供假定可运行的示例。
