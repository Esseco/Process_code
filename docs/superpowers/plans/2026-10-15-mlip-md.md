# MLIP MD Implementation Plan

> **For agentic workers:** Use executing-plans inline. User preferences override forced worktrees, per-task commits, and delegated review.

**Goal:** Provide configurable MACE/SevenNet/CHGNet/ORB MD with independent or chained NVT/NPT stages.
**Architecture:** Lazy calculator factories supply one ASE calculator to run_md. Each call copies input atoms, inherits existing momenta unless initialization is requested, and produces a trajectory, CSV, final state and JSON report. An editable example loops over configured stages and reuses the calculator.
**Tech Stack:** Existing ASE NoseHooverChainNVT / IsotropicMTKNPT, numpy, Python unittest; existing model environments only.
**Spec:** User-approved design in this conversation: single-stage MD, independent NVT/NPT, optional sequential stages, explicit units and random seed, no automatic deletion, no exact restart claim.

## Global Constraints

- Preserve all existing public interfaces and unrelated working-tree changes.
- Tests use py1 and EMT/mock loaders. User explicitly requests no local model environment adjustments or real accelerator setup.
- No model imports/calculations at module import time; no added training dependencies.
- NPT defaults to isotropic; later user-authorized extension adds full MTKNPT and positive-integer chain/substep controls. Reject unsupported constraints. NVT may run without stress; NPT requires stress and 3D PBC.
- Continuation preserves momenta/cell/positions; thermostat/barostat auxiliary state resets at stage boundaries.

## Review Focus

- Velocity initialization cannot silently erase or replace existing momenta.
- Invalid parameters and existing outputs fail before writing or starting dynamics.
- Pressure includes kinetic stress with explicit bar conversion.
- Final step must appear even when output intervals do not divide the step count.
- Model or nonfinite-state failures must not create a completed report.
