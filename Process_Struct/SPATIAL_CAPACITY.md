# CCNB 空间位点容量

## 目标与接口

给定结构，先从移除 Na/Li 后的 CCNB 网络找满足截止半径的贯通通道，再从通道位点估计可同时容纳的离子数，并换算成 mAh/g。使用已有 ccnb 环境。

```python
from Process_Struct import estimate_spatial_capacity

result = estimate_spatial_capacity(
    structure, mobile_ion="Na", cutoff_radius=0.8,
    min_site_distance_A=2.0,
)
capacity = result["capacity_mAh_g"]
```

- 输入：有序 pymatgen Structure 或结构路径；Na/Li 必须存在，沿用现有 CCNB 去迁移元素接口。
- 参数：`cutoff_radius` 为候选间隙最小自由半径（默认 0.8 Å）；`min_site_distance_A` 为所选离子位点的最小间距（默认 2 Å）。二者分别约束离子与框架的空间适配、离子之间的排斥。
- 候选：读取按截止半径筛出的 `structure.net`，只使用 dimensionality 为 1/2/3 的贯通分量。排除孤立间隙和 0D 分量；无贯通通道时位点数和容量均为 0。保留同一贯通分量内的支路节点。瓶颈不是存储位点；对称标签相同但位置不同的节点仍分别参与筛选。跨通道重复的周期位置合并，分数坐标按 NET 精度取六位小数；其余近邻仍由 2 Å 排斥规则处理。
- 筛选：按自由半径从大到小做一次贪心筛选，每选入一个位点就排除周期最短距离不足阈值的剩余位点。适合快速粗筛；**不保证全局最大位点数，结果可能小于原多起点估计**。周期重叠位置通过距离排斥，不重复装入；非正交晶格使用 pymatgen 距离计算。
- 周期性：还检查同一位点在邻晶胞中的复制。如果晶格存在短于间距的平移矢量，报错并要求更大超胞；允许部分占位的超胞构型可能装入更多位点。
- 输出：`site_count_per_cell`、`candidate_count_per_cell`、`selected_sites`、三个质量口径的容量及模型参数。另返回贯通通道数、维度列表及最高通道维度。所有位点数和质量均对应输入晶胞；不混用约化化学式计量。`candidate_network` 为 `percolating_channels_only`。

## 容量与质量口径

每个位点容纳一个一价 Na/Li，设可行位点数为 N、去迁移离子后框架质量为 M框架、离子原子质量为 M离子：

`capacity_mAh_g = 26801.481145 × N / (M框架 + N × M离子)`。

默认使用所选位点全部填满后的质量，与组分容量的最大填充态口径对应。另返回框架质量口径 `capacity_mAh_g_framework_mass_basis` 和输入结构质量口径 `capacity_mAh_g_input_mass_basis`。容量描述这些位点的总装载，并非相对于输入结构还能嵌入的容量。

这是离散 CCNB 贯通通道节点上的几何可行估计，未计电荷中性、能量、位点稳定性或实际可逆性，不能作为真实材料最大容量。仅用通道连通、自由半径和节点排斥，未考虑节点间连续空间中的其他可行位置。贯通是在未填充框架上判定；装入离子后的通道阻塞或动力学不在本模型中。
