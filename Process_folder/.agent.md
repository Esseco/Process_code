# Process_folder Agent 项目

## 概述
`Process_folder` 是一个轻量级 Python 工具包模块，提供文件处理与 Excel/CSV 数据清洗的实用函数。

## 项目信息
- **项目名称**: Process_folder
- **所在路径**: `e:\Py-Code\Process_folder`
- **语言**: Python 3
- **许可证**: 未指定

## 模块列表
| 模块文件 | 功能说明 |
|---|---|
| `__init__.py` | 包入口，导出公共接口 |
| `Handle_Excel.py` | CSV 数据清洗（连字符替换） |
| `Handle_File.py` | 文件系统操作（创建目录） |

## 依赖
- **外部依赖**: `pandas`（Handle_Excel.py 使用）
- **内部依赖**: 无（模块间不互相依赖）

## 使用方式
```python
from Process_folder import replace_hyphen, ensure_dir

# 替换 CSV 中指定列的连字符
df = replace_hyphen("data.csv", exclude_cols=["id"])

# 确保目录存在
from pathlib import Path
ensure_dir(Path("./output/"))
