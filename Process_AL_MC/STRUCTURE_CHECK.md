# 公共结构检查

`Process_AL_MC.structure_check` 只使用 numpy/pymatgen，不加载模型、不写文件、不改变随机种子。相图核查和 MC 共用此处的周期 TM–O 骨架算法；应用层继续负责文件校验和、能量绑定、搜索边界与排除策略。

```python
from Process_AL_MC import check_structure, LayeredFrameworkReference

reference = LayeredFrameworkReference(initial_structure)  # 每条运行只算一次
report = check_structure(
    candidate_structure,
    reference=reference,
    energy_per_atom=-5.0,  # eV/atom，可省略
    check_framework=True,
)
```

- `passed`：本次请求的检查未发现明确问题，不等于物理有效性的证明。`scope=basic` 不代表已检查骨架。
- `invalid`：数据/组成/几何明确不合格，或者既有三截断判据确认超出层状骨架搜索域，可以排除。
- `uncertain`：初始参考未确认为层状、位点对应不明、部分重构或无序占位等，保留证据；MC 当前显式采用 `retain_with_evidence`，不把未知记录成通过。

基础检查包含空结构、坐标和晶胞有限性、正体积、可选能量有限性、可选组成守恒及短程周期邻居。最小允许距离默认沿用 0.6 Å，属于防重合的粗筛，不是元素对化学键长模型。不同原子完全重合及过短的自身周期镜像也会检出。返回的 `minimum_distance` 是截断范围内最近距离；`None` 表示未发现截断范围内的邻居，不是全局最近原子距离。

骨架检查复用既有规则：初始结构的第六氧近邻确定三个固定截断；全部截断下，同一初始相邻 TM 区域失去二维连通，才确认层状骨架破坏。初始拓扑和截断缓存；每个候选只算一次最大截断邻居表，供三个图共用。不根据最终塌缩结构放宽截断。TM 元素交换允许发生，整体组成必须守恒，O/TM/碱金属位点角色必须对应；文件调用者还需验证来源和序号绑定。无法建立对应时返回未知。

## MC 接入

`LayeredOxide_MCOrderingClass` 的初始结构弛豫前做基础检查，弛豫后检查几何/骨架；明确无效初始结构结束该任务，由既有批处理隔离失败并继续其他任务。每个 trial 弛豫后做基础检查；绝对能量差达到阈值或可能进入 pool 时才增加骨架检查。检查在接受状态、最低能量和 pool 更新之前完成。

```python
runner.run(
    ...,
    structure_check_parameters={
        "minimum_distance": 0.6,          # Å
        "energy_jump_per_atom": 0.05,     # eV/atom，仅触发核查
    },
)
```

也可在构造器中传入同一参数；仅支持上述两个有限正数。未给出时使用上述默认值。初始参考永远绑定弛豫前结构，不随当前链漂移。明确无效的 trial 记为 `structure_rejected`，消耗实际步骤/预算，保留访问记录，不改变当前结构/占位、最低能量、改善步或 pool；继续执行并正常遵守 patience 和 checkpoint。结果中保留排除原因和检查计数。pool 和 trace 只存摘要，不重复存拓扑图。

独立 `ordering.search.run_chain` 的每个已收敛同相排序候选也复用此模块；明确无效观察保留在原始记录与 diagnostics 中，`ranking_eligible=False`，不能更新链或排名，后续 trial 继续。各条链缓存自己的初始参考。CSV 的 `structure_check` 列保留检查摘要。这里的所有可排名观察都需要骨架检查，能量变化不作为直接排除理由。

公共模块随 `_bundle_mc_backend` 一起进入新准备的远端任务。既有上传包、科学结果、模型、数据库和运行中服务不重写；历史结果没有该字段时，不能声称已通过新检查。单结构 `Process_MLIP.relax_structure_mace` 本轮未改变行为。

## v2：复用邻居表的局部配位检查（2026-10-21）

规则版本 `periodic-tm-o-rank-local-coordination-v2`。v1仅检查周期连通时，会漏掉局部严重配位变化而二维网络仍连通的结构。v2在原有拓扑判据之外增加以下充分条件，不把所有非六配位都直接判坏：

1. 固定使用可信初始结构给出的三个截断；只有初始在三个截断下都恰为O6的TM位点才可用于确认变化。
2. 同一TM在三个截断下持续欠配位（均小于6），或持续过配位（均大于6），才算持续变化。不能把低截断下5配位、高截断下7配位直接合并成已确认损坏。
3. 至少两个原本相邻的TM满足上述条件；单TM周期原胞按其周期网络判断。孤立变化、截断敏感或初始证据不足返回未知，继续采用retain_with_evidence。

这是针对初始O6层状搜索域的约束，不是通用晶体有效性或重构相能量错误的判定。没有新增能量阈值/模型调用/逐条人工确认流程。

初始配位计数在构建参考时，从已有的最大截断邻居表缓存；候选的局部计数与原有三个拓扑图共用同一个邻居表。没有增加邻居搜索。日志仅保留计数和规则摘要，逐位点数组在公共完整返回值中可查；confirmed局部变化的failed_checks为local_coordination。现有两个MC调用方在更新链/最低能量/pool/排名前排除该候选，实际步数保留并继续。相图适配器复用相同判据，报告缓存指纹加入结构规则版本。

## v3：截断敏感降为提示（2026-10-21）

规则版本 `periodic-tm-o-rank-local-coordination-v3`。只排除证据明确的异常，其他候选保留并继续。v2 的明确异常判据优先、不放宽；角度变化本身不导致剔除。

对仅小截断配位变化的未知项，只有同时满足以下条件才返回 `passed`，并在 `framework.warnings` 保留 `cutoff_sensitive_coordination`：

1. 初始所有 TM 在三个截断下都为 O6；最终三个截断均保留二维骨架。
2. 最终中间和最大截断下所有 TM 都恰为六配位，中间截断不增加容差。
3. 六氧壳层距最大截断至少 0.1 Å；所有 TM 位点的八面体角度 RMS ≤12°（六氧 15 个夹角排序后对理想的 12×90°、3×180°计算 RMS）。

返回 `framework.local_coordination.status=cutoff_sensitive` 和 `framework.cutoff_sensitivity` 标量证据；compact 摘要保留提示与筛查参数，不复制逐位点数组。`no_clear_destruction`/`passed` 仍只表示未发现明确问题，不是物理有效性证明。较大角度畸变、拓扑敏感、中间截断配位变化、参考不足等继续 `uncertain`/`retain_with_evidence`，不要求逐条人工阻塞；人工可按提示复核。

TM 掩码随初始参考缓存；角度筛查只对上述候选未知项运行，复用已算好的最大截断邻居表，不新增搜索、模型调用或能量计算。常规通过项和明确异常项跳过角度筛查。原有 MC 两个调用方不需要修改：明确 invalid 才排除且继续；未知和附提示通过项保留。
