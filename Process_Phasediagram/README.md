# Process_Phasediagram

插层电极相图绘制与 Benchmark：凸包形状误差、相区间 IoU。类型：工具包。

## 输入与输出

- 输入：绘图：x/eform/phase/is_stable；评价：预测/参考下凸包顶点或相存在区间字典。
- 输出：Matplotlib figure/axes，或 hull_error/integral_error、phase_error/mean_iou/phase_iou。
- 依赖：numpy；绘图另需 matplotlib，CSV 示例需 pandas（Python >= 3.11）。默认先使用 py1；缺依赖时检查现有专用环境，不自动安装或升级。

## 功能入口

| 文件 | 函数 / 类 | 用途 |
|---|---|---|
| [metrics.py](metrics.py) | `calculate_hull_error` | Return the exact mean absolute difference between endpoint-relative hulls. |
| [metrics.py](metrics.py) | `calculate_phase_iou_error` | Return macro-averaged phase IoU error after symmetric interval dilation. |
| [plotting.py](plotting.py) | `plot_phase_diagram` | Plot supplied formation energies and global stability flags. |
