# Ehull_test

凸包相关 CHGNet 数据集与训练器试验。类型：训练实验。

## 输入与输出

- 输入：训练结构、能量/力/应力/磁矩及 hull 标签。
- 输出：数据加载器、训练模型及损失。
- 依赖：chgnet, torch, pymatgen, numpy。默认先使用 py1；缺依赖时检查现有专用环境，不自动安装或升级。
